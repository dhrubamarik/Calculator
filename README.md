🧮 Neumorphic Calculator

A sleek and modern calculator web app built using HTML, CSS, and JavaScript.
This project features a clean neumorphic UI design with smooth interactions and responsive layout.

🚀 Features:
<br>
Basic arithmetic operations: ➕ ➖ ✖️ ➗
<br>
Percentage calculation (%)
<br>
Clear (AC) and Delete (DEL) functionality
<br>
Decimal support
<br>
Double zero (00) input
<br>
Responsive and centered layout
<br>
Stylish neumorphism-inspired UI
<br>
🛠️ Tech Stack :
<br>
HTML5 – Structure
<br>
CSS3 – Styling (Neumorphism design)
<br>
JavaScript  – Logic & functionality
